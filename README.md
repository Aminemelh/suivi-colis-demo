# Suivi colis — démo

Démo d'un tableau de bord pour agents d'immeuble : casiers à colis, temps de récupération par résident,
et registre de la « salle gestionnaire » avec lecture d'étiquette par photo.

Toutes les données sont **inventées** (500 résidents fictifs). Les colis ajoutés dans la salle gestionnaire
restent dans le navigateur de l'appareil. Les photos d'étiquettes sont lues sur l'appareil et ne sont envoyées nulle part.
